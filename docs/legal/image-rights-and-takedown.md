# 이미지 권리 정책 및 권리 침해 신고·조치 가이드

> 프로젝트: **perfumeishuman — "향수가 사람이라면?"**
> 작성일: 2026-08-16 · 상태: **확정 (운영 문서)**
> 근거: [ADR 0009](../adr/0009-perfume-image-sourcing-and-takedown.md) · 관련: [terms-of-service.md](./terms-of-service.md)
>
> **본 문서는 법률 자문이 아니다.** 운영자가 스스로 지킬 기준과 절차를 문서화한 것이며, 실제 분쟁 발생 시 변호사 확인을 받는다.

## 1. 목적

이 문서는 두 가지를 정한다.

1. **사전 예방** — 향수 이미지를 어떤 기준으로 수집·가공·게시할 것인가
2. **사후 대응** — 권리자가 이의를 제기했을 때 **다투지 않고 얼마나 빨리 내릴 것인가**

핵심 원칙은 하나다. **분쟁하지 않는다. 이의가 오면 먼저 내린다.** 1인 운영 서비스에서 분쟁 비용은 어떤 이미지의 가치보다도 크다. 이 원칙이 성립하려면 (가) 대상 이미지를 즉시 특정할 수 있어야 하고 (나) 이미지를 내려도 서비스가 정상 동작해야 한다. 두 조건은 §2.4와 §2.5에서 설계로 보장한다.

## 2. 이미지 조달 원칙

### 2.1 조달 방식

향수 이미지는 **브랜드 공식 웹사이트 제품 상세페이지의 단순 제품사진에서 배경을 제거(누끼)해 가공한 이미지**를 사용한다.

### 2.2 수집 기준 — 허용과 배제

| | 기준 |
|---|---|
| ✅ **허용** | 흰색·단색 배경에 **제품만 정면으로** 촬영된 단순 제품사진 (팩샷) |
| ❌ **배제** | 모델·인물이 등장하는 사진 |
| ❌ **배제** | 소품·배경·공간이 함께 연출된 이미지컷 |
| ❌ **배제** | 그림자·조명이 작품처럼 연출된 사진 |
| ❌ **배제** | 광고 카피·그래픽·텍스트가 합성된 이미지 |
| ❌ **배제** | 워터마크가 있는 이미지 (제거를 시도하지 말고 수집 자체를 포기한다) |
| ❌ **배제** | 여러 제품이 함께 배치된 구성컷 |
| ❌ **배제** | 브랜드 로고·심볼만 단독으로 사용하는 것 |

이 구분이 정책의 핵심이다. 제품 자체를 충실히 표현한 단순 제품사진은 창작성이 부정될 여지가 있는 반면(대법원 2001. 5. 8. 선고 98다43366 판결 취지), **연출된 이미지 사진은 저작물로 인정된다.** 연출컷을 하나라도 쓰는 순간 이 방어 논리가 통째로 무너지므로 예외를 두지 않는다.

### 2.3 가공 규격

- 배경을 완전히 제거하고 동일 규격(정사각·투명 배경)으로 통일한다
- 원본 이미지 파일을 그대로 재게시하지 않는다 (반드시 가공 후 자체 저장)
- 제품 형상을 왜곡하거나 색상을 임의로 바꾸지 않는다 (소비자 오인 방지)

### 2.4 기록 의무 — 이미지마다 반드시 남긴다

| 기록 항목 | 용도 |
|---|---|
| 원본 출처 URL | 이의 제기 시 대상 특정, 수집 경위 소명 |
| 수집일 / 가공일 | 처리 이력 |
| 브랜드 참조 | **브랜드 단위 일괄 제거**의 전제 |
| 권리 상태 | `정상` / `이의접수` / `비공개` / `영구제거` |
| 제거일·제거 사유 | 신고 대장과 대조 |

> 데이터 모델(5단계)·ERD(6단계)에 반드시 반영한다. 이 기록이 없으면 "즉시 내린다"는 원칙 자체가 실행 불가능해진다.

### 2.5 이미지 없이도 동작하는 설계 (필수)

향수 상세·검색 결과·목록 카드는 **이미지가 없어도 정상 동작해야 한다.** 이미지가 없거나 제거된 경우 향수명·브랜드명 기반 텍스트 카드로 폴백한다.

이 폴백이 이 정책의 실질적 보험이다. 폴백이 있으면 "즉시 내리는 것"이 비용 없는 선택이 되고, 폴백이 없으면 운영자는 내리기를 망설이게 된다. 8단계 UI 디자인의 필수 요구사항이다.

## 3. 게시 시 고지 문구

향수 상세 페이지 하단(또는 이미지 영역 근처)에 상시 노출한다.

> 제품 이미지는 각 브랜드의 제품을 소개할 목적으로 게시되었으며, 브랜드명·제품명·상표에 관한 권리는 각 권리자에게 귀속됩니다. 본 서비스는 해당 브랜드와 제휴·후원 관계가 없습니다.
> 권리 침해에 관한 문의는 `[신고 이메일 — 운영 시작 전 확정]` 으로 접수해 주시면 신속히 조치하겠습니다.

이용약관과 개인정보처리방침 하단, 도움말(`/help`) 페이지에도 신고 창구를 함께 안내한다.

## 4. 권리 침해 신고 접수

### 4.1 접수 창구

| 항목 | 내용 |
|---|---|
| 이메일 | `[운영 시작 전 확정 — 예: report@도메인]` |
| 운영 | 상시 접수, 영업일 기준 처리 |
| 대체 창구 | 서비스 내 문의(도움말 페이지 링크) |

### 4.2 신고 시 기재해 주실 사항

접수 요건을 갖추지 못했다는 이유로 조치를 미루지 않는다. 다만 아래가 있으면 처리가 빨라진다.

1. 신고인의 성명·연락처 (권리자 본인 / 대리인 여부)
2. 권리를 주장하는 근거 (저작권·상표권·기타)
3. **대상 페이지 URL 또는 이미지 위치** (브랜드 전체를 대상으로 하는 경우 브랜드명)
4. 침해라고 판단하는 이유
5. 요청하는 조치 (삭제 / 수정 / 브랜드 전체 제거 등)
6. 신고 내용이 사실이라는 진술

## 5. 처리 절차

```
신고 접수
   ↓  24시간 이내
접수 확인 회신 (담당자·접수번호·예상 처리시각 안내)
   ↓  72시간 이내 (목표 24시간)  ※ 정당성을 다투지 않는다
대상 이미지 즉시 비공개 → 텍스트 카드로 자동 폴백
   ↓
신고인에게 조치 완료 통지
   ↓
신고 대장 기록 · 재수집 금지 목록 등재
   ↓  (필요 시)
브랜드 단위 일괄 제거 · 정책 재검토(ADR)
```

### 5.1 선(先)조치 원칙

**권리자 또는 대리인의 이의가 접수되면 정당성 판단 없이 먼저 내린다.** 우리 판단이 옳은지는 조치 이후에 검토한다. 이 순서를 뒤집지 않는다.

### 5.2 조치 유형

| 유형 | 적용 상황 |
|---|---|
| 개별 이미지 비공개 | 특정 이미지에 대한 이의 |
| **브랜드 단위 일괄 제거** | 브랜드 차원의 이의, 또는 동일 브랜드에서 반복 접수 |
| 재수집 금지 목록 등재 | 제거한 대상은 다시 수집하지 않는다. 관리자 화면에서 경고 표시 |
| 정책 재검토 | 내용증명 수령·반복 이의 시 [ADR 0009](../adr/0009-perfume-image-sourcing-and-takedown.md)를 새 ADR로 재검토 |

### 5.3 이의·복원 절차

권리자가 아닌 제3자의 오신고 등으로 조치가 잘못되었다고 판단되는 경우, 신고인·이의신청인 양측의 소명을 받아 복원 여부를 결정한다. 다만 **판단이 불확실하면 비공개를 유지한다.**

### 5.4 이용자 콘텐츠(시향기)에 대한 신고

시향기 본문에 대한 권리 침해·명예훼손 신고는 기존 신고 기능(S3, `/admin/reports`)과 본 절차를 함께 적용한다. 즉시 조치 원칙은 동일하되, 작성자에게 조치 사실을 통지한다.

## 6. 기록 보관

신고 대장에 아래를 기록하고 **3년간 보관**한다. 처리 이력 자체가 성실 대응의 증거가 된다.

| 필드 |
|---|
| 접수번호 · 접수일시 · 접수 경로 |
| 신고인 정보 · 권리 근거 |

| 조치 내용 · 조치 일시 · 처리자 |

## 7. 운영자 체크리스트

**향수 이미지를 등록할 때마다**

- [ ] 원본이 §2.2 허용 기준(단순 팩샷)에 맞는가
- [ ] 원본 출처 URL을 기록했는가
- [ ] 재수집 금지 목록에 있는 브랜드·제품이 아닌가
- [ ] 워터마크·합성 텍스트가 없는가

**분기마다**

- [ ] 재수집 금지 목록과 실제 게시 이미지 대조
- [ ] 신고 대장 정리
- [ ] 수익화(W1) 도입 논의가 시작되었는가 → 시작되었다면 ADR 0009 재검토

## 8. 참고 법령

| 법령 | 관련 내용 |
|---|---|
| 저작권법 제102조·제103조 | 온라인서비스제공자의 책임 제한, 권리주장자의 복제·전송 중단 요구 및 재개 절차 |
| 부정경쟁방지 및 영업비밀보호에 관한 법률 | 타인의 성과 등 무단사용 |
| 상표법 | 상표적 사용과 지시적 사용의 구분 |
| 정보통신망 이용촉진 및 정보보호 등에 관한 법률 제44조의2 | 사생활 침해·명예훼손 정보에 대한 삭제 요청과 임시조치 |

세부 요건과 적용 여부는 사안에 따라 다르며, 본 문서는 그 판단을 대신하지 않는다.
