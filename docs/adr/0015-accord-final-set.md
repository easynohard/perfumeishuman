# 0015. 계열(accord) 최종 세트 11개 확정

- Status: **Accepted** (2026-10-01 확정)
- 관련 문서: [0003-controlled-vocabulary-tags.md](./0003-controlled-vocabulary-tags.md), [0005-seo-slug-urls.md](./0005-seo-slug-urls.md), [05-data-model.md](../05-data-model.md) §2.3·§2.6·§3.2 E4, [06-erd.md](../06-erd.md) E4

## Context

ADR 0003은 향수의 계열을 "관리자가 지정한 통제 어휘"로 쓰기로 했을 뿐, 세트의 개수·이름·순서는 정하지 않았다. 5단계(`05-data-model.md` §7)와 6단계(`06-erd.md` §4)는 "계열 통제 어휘 최종 세트는 ADR 0003에서 확정"이라고 서로 참조했지만, ADR 0003에는 그 세트가 없어 실제로는 어디에도 확정된 목록이 없었다. 계열 탐색(`/notes`, `/notes/:slug`)은 입문자의 핵심 탐색 경로(1단계 S1)이고, 7단계 API와 운영자 시딩이 이 값에 의존하므로 7단계 착수 전에 확정한다.

## Decision

계열은 아래 **11개**로 확정한다. 표시명은 한글, 슬러그는 영문 소문자(ADR 0005)이며, **표시 순서는 아래 표의 순서 그대로**다(운영자 지정 고정 순서, ADR 0003).

| 순서 | 표시명 | 슬러그 |
|---|---|---|
| 1 | 플로럴 | `floral` |
| 2 | 시프레 | `chypre` |
| 3 | 푸제르 | `fougere` |
| 4 | 시트러스 | `citrus` |
| 5 | 우디 | `woody` |
| 6 | 앰버 | `amber` |
| 7 | 레더 | `leather` |
| 8 | 구르망 | `gourmand` |
| 9 | 마린 | `marine` |
| 10 | 머스크 | `musk` |
| 11 | 알데하이드 | `aldehydic` |

- 표기는 명사형으로 통일한다(`Musky` → `머스크`/`musk`). 슬러그에 악센트 문자를 쓰지 않는다(`Fougère` → `fougere`).
- 향수–계열은 다대다(`05-data-model.md` §2.7)이므로 한 향수에 여러 계열을 붙일 수 있다.
- 노트(개별 향료)는 이 세트와 무관하게 향수의 자유 텍스트 한 줄로 유지한다.

## 검토한 대안

- **7개 내외의 더 적은 계열**: 입문자에게 단순하지만 업계 분류와 어긋나고, 사용자가 제시한 11개 분류가 이미 있어 기각.
- **노트까지 통제 어휘 엔티티로 확장**: 노트별 탐색 화면이 없어 5단계에서 기각한 사항(`05-data-model.md` §2.7)이며, 이번에도 번복할 근거가 없어 유지.

## Consequences

- (+) `/notes` 화면, 계열 슬러그, 운영자 시딩 데이터, 7단계 API 응답 스키마가 확정된 값을 기준으로 진행된다.
- (+) 5·6단계 문서가 ADR 0003을 최종 세트의 출처로 가리키던 순환 참조가 이 ADR로 해소된다.
- (−) 시프레·푸제르·알데하이드는 입문자에게 낯선 전문 용어지만, **계열 한 줄 설명은 두지 않기로 확정**했다(2026-10-01). `accord`에 설명 필드를 추가하지 않으므로 ERD 변경은 없다.
- (+) `06-erd.md` §4의 "계열 통제 어휘 최종 세트(ADR 0003)" 표기는 이 ADR을 가리키도록 정정했다(2026-10-01 승인).
- (−) 세트를 바꾸려면(계열 추가·삭제) 기존 향수–계열 연결과 `accord.perfume_count`의 정합성을 함께 처리해야 한다.
