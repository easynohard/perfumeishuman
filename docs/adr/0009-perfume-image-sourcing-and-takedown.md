# 0009. 향수 이미지는 단순 팩샷 누끼로 조달하고, 권리 이의 제기 시 즉시 내린다

- Status: **Accepted** (2026-08-16 확정)
- 관련 문서: [01-problem-definition-scope.md](../01-problem-definition-scope.md) M2·W1·N12, [03-sitemap-ia.md](../03-sitemap-ia.md) §3 향수 상세, `docs/legal/image-rights-and-takedown.md`, `docs/legal/terms-of-service.md`

> 본 ADR은 법률 자문이 아니다. 운영 판단의 근거를 기록한 것이며, 실제 분쟁이 발생하면 변호사 확인을 받는다.

## Context

향수 상세 페이지(M2)에는 제품 이미지가 필요하다. 입문자 대상 서비스에서 이미지 없는 향수 목록은 탐색 경험을 크게 해친다. 그러나 1인 운영·비수익 MVP에서 브랜드별 제품을 직접 촬영해 조달하는 것은 현실적으로 불가능하다.

운영자는 **브랜드 공식 웹사이트의 제품 상세페이지 이미지에서 배경을 제거(누끼)해 가공한 이미지**를 사용하기로 했다. 이는 타인 사진의 복제·변형에 해당하므로 위험이 0은 아니다. 위험 구조를 정확히 파악한 뒤 대응 체계를 갖춘다.

### 위험 평가

**완화 요인.** 대법원 2001. 5. 8. 선고 98다43366 판결(광고용 제품사진 사건)에서, 제품 자체를 충실하게 표현한 단순 제품사진은 촬영자의 개성이 드러나지 않아 **창작성(저작물성)이 부정**되고, 배경·소품과 함께 연출된 이미지 사진만 저작물로 인정됐다. 흰 배경 정면 팩샷이 원본이라면 저작권 침해 주장이 성립하기 어려울 수 있다. 나아가 **누끼 작업은 창작성이 인정되는 부분(배경·조명 연출)을 제거하는 방향**이므로 이 논리를 약화시키지 않는다.

**남는 위험.**

| # | 위험 | 성격 |
|---|---|---|
| R1 | 원본이 연출컷(모델·소품·배경·조명 연출)이면 저작물성이 인정되어 복제·2차적저작물작성권 침해가 성립할 수 있다 | 수집 기준으로 통제 가능 |
| R2 | 부정경쟁방지법상 타인의 성과 무단사용 주장 | 통제 불가 — 사후 대응 |
| R3 | 수집 대상 사이트 이용약관(크롤링·이미지 사용 금지) 위반 = 계약 위반 | 통제 불가 — 사후 대응 |
| R4 | **수익화(W1: 제휴 링크·광고) 도입 시 "상업적 이용" 성격이 강해져 R2·R3 위험이 상승** | 재검토 트리거 |
| R5 | 상표권·디자인권 (병 형태, 로고) | 제품을 있는 그대로 지시하는 사용은 통상 허용 범위. 로고 단독 사용은 금지 |

결국 **위험을 0으로 만들 수는 없고, 이의 제기 시 다투지 않고 즉시 내릴 수 있는 구조**를 만드는 것이 실질적 대응이다.

## Decision

### 1. 수집 기준 — 단순 팩샷만

- **허용**: 흰색·단색 배경에 제품만 정면으로 촬영된 단순 제품사진
- **배제**: 모델·인물이 등장하는 사진, 소품·배경이 연출된 이미지컷, 그림자·조명이 작품처럼 연출된 사진, 광고 카피·그래픽이 합성된 이미지, 워터마크가 있는 이미지, 여러 제품이 배치된 구성컷

R1을 통제하는 유일한 수단이므로 예외를 두지 않는다.

### 2. 가공 규격

배경을 완전히 제거하고 동일 규격(정사각 투명 배경)으로 통일한다. 워터마크 제거를 시도해야 하는 이미지는 **가공하지 말고 수집 대상에서 배제**한다.

### 3. 추적 기록 의무 (데이터 모델 요구사항)

모든 이미지에 대해 **원본 출처 URL · 수집일 · 가공일 · 브랜드 참조**를 기록한다. 이의 제기 시 대상 이미지를 즉시 특정하고, **브랜드 단위로 일괄 제거**할 수 있어야 한다. 5단계 데이터 항목·6단계 ERD에 반영한다.

### 4. 선(先)조치 원칙

권리자 또는 그 대리인의 이의가 접수되면 **정당성을 다투지 않고 먼저 비공개 처리한다.** 접수 확인 24시간 이내, 비공개 조치 72시간 이내(목표 24시간). 절차는 `docs/legal/image-rights-and-takedown.md`에 따른다. 1인 운영에서 분쟁 비용은 어떤 이미지의 가치보다도 크다.

### 5. 이미지 없이도 동작하는 설계 (필수)

향수 상세·검색 결과·목록 카드는 **이미지가 없어도 정상 동작해야 한다.** 이미지가 없거나 제거된 경우 향수명·브랜드명 기반 텍스트 카드로 폴백한다. 이 폴백이 있어야 "즉시 내리는 선택"이 비용 없는 선택이 된다. 8단계 UI 디자인의 필수 요구사항으로 둔다.

### 6. 게시 시 고지

향수 상세 페이지에 상표·제품명의 권리 귀속과 권리 침해 신고 창구를 고지한다. 문구는 `docs/legal/image-rights-and-takedown.md` §3.

### 7. 재검토 트리거

다음 중 하나가 발생하면 본 ADR을 새 ADR로 재검토한다.

- **수익화(W1) 도입** — 제휴 링크·광고 게재 시 (R4)
- 특정 브랜드의 이의 제기 또는 내용증명 수령
- 브랜드 공식 이미지 제휴·API 등 정식 조달 경로 확보
- 사용자 이미지 업로드 기능 도입 검토 시 (MVP 범위 밖)

## 검토한 대안

- **이미지 없이 텍스트만**: 위험 0이지만 입문자 대상 탐색 경험이 크게 나빠진다. 다만 이 안을 **폴백(§5)으로 채택**해 리스크 해소 수단으로 재활용했다.
- **직접 촬영 조달**: 가장 안전하나 1인 운영에서 브랜드별 제품 확보가 불가능해 기각. 향후 대표 향수 일부라도 직접 촬영으로 대체할 수 있으면 위험이 낮아지므로, 장기 개선 방향으로 남긴다.
- **사용자 업로드 허용**: 조달 부담은 줄지만 침해 이미지 유입 통제가 불가능해지고 모니터링 부담이 생긴다. MVP 범위(W7 자동 필터링 제외)와도 맞지 않아 기각.
- **연출컷 포함 전면 수집**: 이미지 품질은 좋아지나 R1이 현실화된다. 완화 논리(98다43366)가 통째로 무너지므로 기각.

## Consequences

- (+) 이미지 있는 향수 상세를 비용 없이 확보한다.
- (+) 이의 제기 시 다툼 없이 즉시 대응할 수 있는 절차와 데이터 구조를 갖춘다 — 실제 위험은 "이미지를 잃는 것"까지로 한정된다.
- (+) 폴백 설계 덕분에 이미지 제거가 서비스 장애로 이어지지 않는다.
- (−) 데이터 모델에 출처 URL·수집일·권리 상태·제거 이력 필드가 추가된다.
- (−) 향수 등록 시 "단순 팩샷인지" 사람이 판단해야 하는 운영 부담이 생긴다. 관리자 화면(`/admin/catalog`)에 수집 기준 안내와 출처 URL 입력을 필수로 둔다.
- (−) 위험이 완전히 사라지지는 않는다. 특히 **수익화 시점에 정책 재검토가 강제**되며, 그때 이미지 조달 방식을 바꿔야 할 수 있다.
- (−) 신고 접수용 이메일 주소와 응답 체계를 운영자가 상시 유지해야 한다.
