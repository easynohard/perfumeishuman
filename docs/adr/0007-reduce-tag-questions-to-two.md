# 0007. 태그 질문 4종 → 2종 축소 ("만나는 상황"·"어울리는 사람" 삭제)

- Status: **Accepted** (2026-08-16 확정)
- 관련 문서: [0003-controlled-vocabulary-tags.md](./0003-controlled-vocabulary-tags.md), [0004-single-page-writing-form.md](./0004-single-page-writing-form.md), [0006-tag-vocabulary-and-answer-structure.md](./0006-tag-vocabulary-and-answer-structure.md) (본 ADR이 대체), [04-wireframes.md](../04-wireframes.md) §1.3·§2.8·§4.1·§6, [02-user-stories.md](../02-user-stories.md) D1

## Context

0006에서 확정한 태그 질문 4종(나이대·성격·만나는 상황·어울리는 사람) 중 뒤의 두 질문이 서비스의 핵심 컨셉인 의인화("향수가 사람이라면?")와 어긋난다는 문제가 드러났다.

- "이 사람을 언제 만날 것 같나요?"는 응답 선택지가 계절(봄/여름/가을/겨울)을 포함하는데, 사람에게 "당신을 어느 계절에 만나나요"라고 묻는 것은 부자연스럽다. 향수의 속성(사용 시즌·TPO)을 사람 질문으로 억지로 포장한 형태였다.
- "누구에게 잘 어울릴까요?"도 마찬가지로 사람을 소개하는 문맥에서 나올 질문이 아니다 — 이건 향수 자체의 추천 대상을 묻는 것이지, "이 사람"에 대한 질문이 아니다.

두 질문 모두 "인물 프로필" 형태(§2.8 "이 사람의 프로필" 표, §1.3 카드)로 노출되기 때문에, 어색함이 작성 화면뿐 아니라 조회 화면에도 그대로 드러난다. 컨셉 일관성이 재미(N3, 서비스의 최대 관심사)를 좌우하므로, 데이터 모델·API 설계(6~7단계)가 시작되기 전인 지금 정리하기로 했다.

## Decision

태그 질문을 **나이대 · 성격 2종**으로 축소한다. "만나는 상황"과 "어울리는 사람" 질문과 그 응답 데이터 구조는 설계에서 완전히 제거한다.

- 작성 폼(`/write`)의 "이 사람의 프로필" 섹션은 나이대(단일 선택)·성격(1~3개)만 남는다. 나머지 규칙(탭만으로 응답, 자유 입력 없음, 각 최소 1개 필수)은 0003·0006 그대로 유지.
- 시향기 카드(§1.3)의 대표 태그는 나이·성격 2개로 축소 (기존엔 나이·성격·만나는 상황 3개였음).
- 시향기 상세 "이 사람의 프로필" 표(§2.8)에서 "만나는 때"·"어울리는 사람" 행 삭제.
- 0006에 정의됐던 "만나는 때"·"어울리는 사람"의 선택지 세트·두 축 구조·카디널리티 규칙은 폐기한다.

## 검토한 대안

- **질문 문구만 수정해서 유지** (예: "이 사람을 언제 만나면 좋을까요?"): 문구를 아무리 다듬어도 "계절"이라는 응답 선택지 자체가 사람에게 묻기엔 어색함이 남아 기각.
- **향수 속성으로 재배치** (계열/노트처럼 향수 메타데이터로 이동): TPO·추천 대상 정보 자체의 가치는 인정하지만, 이번 결정의 핵심은 "의인화 프로필에서 빼는 것"이지 "다른 곳으로 옮기는 것"이 아니다. 필요성이 재확인되면 별도 ADR로 재도입 여부를 논의.
- **4종 유지**: 데이터가 풍부해지는 장점은 있으나, 작성 부담(질문 2개 추가 응답)과 컨셉 어긋남이라는 비용이 더 크다고 판단해 기각.

## Consequences

- (+) 태그 질문 전체가 "이 사람을 소개한다"는 컨셉에 자연스럽게 들어맞는다 — 나이·성격은 사람에 대한 질문으로 어색함이 없음.
- (+) 작성 폼이 짧아져 완주율에 유리하다 (D1, 0004의 목표와 일치).
- (+) 6단계 ERD가 단순해진다 — 태그 그룹이 2개(단일 선택 1개 + 다중 선택 1개)로 줄고, "어울리는 사람"의 두 독립 축 같은 복잡한 구조가 사라진다.
- (−) "만나는 상황"·"어울리는 사람"이 제공하던 탐색·추천 정보(예: "데이트용 향수 찾기")를 MVP에서 잃는다. 향후 필요성이 확인되면 향수 자체의 속성(계열·노트처럼)으로 재도입을 검토할 수 있다.
- (−) 0006에 정의된 선택지 세트(계절 4종, 상황 4종, 연령대×성별 이미지 두 축)는 폐기 — 관련 UI 문구·데이터 준비 작업이 무효화된다.
