# 0006. 시향기 태그 선택지 세트와 응답 구조 확정

- Status: **Accepted** (2026-08-14 확정)
- 관련 문서: [0003-controlled-vocabulary-tags.md](./0003-controlled-vocabulary-tags.md) (통제 어휘 원칙 — 본 ADR은 그 선택지의 최종 세트를 확정), [04-wireframes.md](../04-wireframes.md) §4.1·§6

## Context

ADR 0003이 태그를 관리자 지정 통제 어휘로 정하면서 선택지의 최종 세트 확정을 4단계 와이어프레임으로 미뤘다. 선택지 세트와 질문별 응답 규칙(단일/복수, 최소/최대 개수)은 6단계 ERD의 테이블 구조·제약과 7단계 API의 검증 규칙을 직접 결정하므로, 되돌리면 기존 시향기 데이터의 마이그레이션이 필요한 결정이다.

## Decision

태그 질문 4종의 선택지와 응답 규칙을 다음과 같이 확정한다. 모든 질문은 각 최소 1개 필수, 탭만으로 응답, 자유 입력 없음 (0003 유지).

| 질문 | 선택지 | 응답 규칙 |
|---|---|---|
| 나이 (몇 살쯤일까요?) | 10대 / 20대 / 30대 / 40대 / 50대+ (5구간) | **정확히 1개** (단일 선택) |
| 성격 (어떤 분위기의 사람인가요?) | 차분한 · 장난기 많은 · 도도한 · 다정한 · 신비로운 · 시크한 · 순수한 · 자유로운 · 섹시한 · 지적인 · 상큼발랄한 · 우아한 (12개) | **1~3개** |
| 만나는 때 (언제 만날 것 같나요?) | 계절 4종(봄/여름/가을/겨울) + 상황 4종(데일리/데이트/출근/특별한 날) 혼합 풀 8개 | **1개 이상** |
| 어울리는 사람 (누구에게 잘 어울릴까요?) | 연령대 5구간(나이 질문과 동일 구간) + 성별 이미지 3종(여성적/남성적/중성적) — **두 독립 축** | 두 축 합산 **1개 이상**, 각 축 복수 선택 가능 |

- "어울리는 사람"은 하나의 질문이 두 개의 태그 그룹(연령대 · 성별 이미지)을 갖는 구조다. 연령대 구간의 어휘는 나이 질문과 공유하되, 응답은 별개 그룹으로 저장한다.
- 피드·목록의 시향기 카드에는 나이·성격·만나는 때에서 각 1개씩 대표 태그를 노출하고, 어울리는 사람은 카드에서 생략한다 (카드 무게 관리 — 04 문서 §1.3).

## 검토한 대안

- **성격 8개 축소안**: 선택 피로는 줄지만 표현 폭이 좁아져 "원하는 표현이 선택지에 없는" 위험(0003 Consequences)이 커져 기각. 12개는 대비를 이루는 짝(차분한↔장난기 많은 등)으로 구성해 스캔 부담을 낮춘다.
- **어울리는 사람을 조합 카드로 제시** (예: "20대 여성적 이미지" 카드 15개): 재미는 있으나 카드 수 폭발(5×3)과 일러스트 제작 부담으로 MVP 범위를 넘어 기각. 두 축 독립 선택이 조작도 데이터도 단순하다.
- **태그 질문 전체 선택화** (필수는 자유 서술만): 작성 부담은 줄지만, 태그는 카드 노출·계열 탐색·"이 사람의 프로필" 표의 재료라 최소 1개 보장이 콘텐츠 품질 유지에 필요하다고 판단, 논의 후 원안(각 최소 1개 필수) 유지로 재확정 (2026-08-14).

## Consequences

- (+) 6단계 ERD 설계 가능: 태그 그룹(질문) – 선택지 – 시향기의 다대다 구조에 그룹별 카디널리티 제약(단일 / 1~3 / 1+)이 확정됐다. "어울리는 사람"의 두 축은 두 개의 태그 그룹으로 모델링한다.
- (+) 7단계 API의 작성 요청 검증 규칙(질문별 최소/최대 개수)이 그대로 도출된다.
- (−) 성격 최대 3개 등 개수 제한은 클라이언트만이 아니라 서버에서도 검증해야 한다.
- (−) 선택지 개정(추가·삭제·문구 변경)은 기존 시향기와의 정합성 문제를 낳는다 — 0003 Consequences의 개정 절차 필요성이 이 세트에 그대로 적용된다.
