# 0036. 출시 때 Supabase는 유료(Pro)로 전환하고, Vercel은 수익화 전까지 무료(Hobby)로 둔다 — 월 비용 0원 → 약 3.7만 원 → 약 6.5만 원

- Status: **Accepted** (2026-11-17 — 9단계 기술 스택 10번 결정, 사용자 승인)
- 관련 문서: [ADR 0027](./0027-hosting-vercel-db-supabase-seoul.md)(Decision 3 "유료 전환 시점은 ⑩에서 정한다"를 이 ADR이 채운다) · [ADR 0028](./0028-login-kakao-better-auth-session.md) · [ADR 0029](./0029-image-storage-supabase-two-buckets.md) · [ADR 0033](./0033-test-strategy-and-ci-quality-gates.md) · [ADR 0035](./0035-privacy-outsourcing-and-overseas-transfer.md) · [01](../01-problem-definition-scope.md) W1(수익화)·N8(1인 운영)

## Context

ADR 0027은 개발 기간에 Vercel·Supabase 무료 플랜을 쓰고, 유료 전환 시점은 9단계 ⑩ 비용 추정에서 정한다고 했다. ①~⑨로 외부 서비스가 모두 정해졌다: Vercel(서버), Supabase(DB·이미지 저장), 카카오(로그인), GitHub(코드 보관·CI).

2026-11-17 각 사 공개 자료로 확인한 사실(출시 전 공식 가격 페이지로 재확인):

- **Supabase 무료**: DB 500MB, 파일 1GB, **자동 백업 없음**, 1주일 이용이 없으면 일시정지. **Pro는 월 $25**: 매일 백업·7일 보관, 전송량 월 250GB 포함, 일시정지 없음, Smart CDN(파일 변경·삭제 시 캐시 자동 무효화, ADR 0029).
- **Vercel Hobby(무료)**: 개인·**비상업** 용도만, 한도 초과 시 해당 기능 30일 정지. **Pro는 사용자당 월 $20**(ADR 0027).
- 카카오 로그인은 무료다. GitHub Actions는 비공개 저장소도 월 2,000분 무료다.

## Decision

1. **개발 중**: 모든 서비스를 무료로 쓴다. 월 0원.
2. **출시(수익 없음)**: **Supabase만 Pro로 전환**한다. 회원이 쓴 시향기를 잃지 않도록 자동 백업이 필수이고, 일시정지가 없어야 하며, 이미지 즉시 내리기(ADR 0029)가 Smart CDN으로 빨라진다. Vercel은 광고·제휴 링크가 없는 동안 비상업 조건에 맞으므로 Hobby를 유지한다.
3. **수익화(W1) 시작**: 광고·제휴 링크 등 수익 기능을 켜기 **전에** Vercel을 Pro로 전환한다(ADR 0027 Decision 3).
4. CI는 GitHub Actions 무료 한도 안에서 운영한다. 화면 흐름·속도 검사처럼 오래 걸리는 검사는 `main` 반영 시점에만 돌리는 등으로 조정한다(ADR 0033).

### 시기별 월 비용

| 항목 | ① 개발 중 (지금~출시) | ② 출시 (수익 없음) | ③ 수익화 시작 후 |
|---|---|---|---|
| Vercel (사이트 서버) | 0원 (무료) | 0원 (무료) | $20 ≈ 2.8만 원 (유료 필수) |
| Supabase (DB·이미지) | 0원 (무료) | $25 ≈ 3.5만 원 (유료 추천) | $25 ≈ 3.5만 원 |
| 카카오 로그인 | 0원 | 0원 | 0원 |
| GitHub (코드 보관·CI 로봇) | 0원 | 0원 | 0원 |
| 도메인 (사이트 주소) | 필요 없음 | 연 1.5~3만 원 (월 약 2천 원) | 같음 |
| **합계 (월)** | **0원** | **약 3.7만 원** | **약 6.5만 원** |

> 기준: 2026-11-17 각 사 공개 가격, 1달러 ≈ 1,400원으로 계산한 대략적인 값. 출시 전 공식 가격 페이지로 재확인한다.

### 비용이 늘어날 수 있는 경우

1. **통신비밀보호법상 접속 기록 3개월 보관 의무가 적용될 때**(ADR 0035 출시 전 확인 항목): 로그를 오래 보관하려면 Vercel Pro와 로그 저장 공간이 필요해 **월 약 3~4만 원이 추가**될 수 있다.
2. **방문자가 아주 많아질 때**: Supabase Pro의 포함 전송량(월 250GB)을 넘으면 초과분이 과금된다. 향수 사진 1장 약 100KB 기준 대략 월 200만 회 이상 표시해야 넘는 양이라 초기에는 해당하지 않는다. 넘을 조짐이 보이면 이미지 저장소를 Cloudflare R2로 옮기는 것을 검토한다(ADR 0029 대안).

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 출시 때도 전부 무료 | Supabase 무료는 자동 백업이 없어 사고 시 회원 글을 잃을 수 있고, 일시정지 위험이 있다 |
| 출시 때 둘 다 유료 | 수익이 없는 동안은 Vercel Hobby의 비상업 조건을 충족하므로 월 2.8만 원을 아낄 수 있다 |
| 수익화 후 Vercel 전환 | 수익 기능을 켜는 순간 Hobby 조건 위반이므로 "켜기 전" 전환으로 정한다 |

## Consequences

- (+) 개발 중 비용은 0원이고, 출시 후에도 월 4만 원 안쪽으로 시작한다.
- (+) 출시 시점부터 매일 백업이 되어 회원 데이터 손실 위험이 크게 줄어든다.
- (−) 출시 직후 Vercel Hobby의 한도 초과 시 30일 정지 위험이 남는다. 사용량을 모니터링하고, 한도에 가까워지면 Pro 전환을 앞당긴다.
- (−) 가격·한도는 각 사가 바꿀 수 있어, 출시 전과 수익화 전에 다시 확인해야 한다.
- 9단계 결정 10항목이 모두 정해졌다. 요약은 `docs/09-tech-stack.md`에 이 표와 함께 정리한다.
