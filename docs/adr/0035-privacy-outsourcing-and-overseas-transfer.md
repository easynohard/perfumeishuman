# 0035. 처리위탁은 Vercel·Supabase 두 곳, 카카오는 위탁이 아님, 국외 이전은 보수적으로 공개, 접속 로그는 최대 7일

- Status: **Accepted** (2026-11-17 — 9단계 기술 스택 9번 결정, 사용자 승인)
- 관련 문서: [legal/privacy-policy.md](../legal/privacy-policy.md) 제1조·제6조 · [ADR 0010](./0010-minimal-personal-data-collection.md)(최소 수집, IP 미저장) · [ADR 0027](./0027-hosting-vercel-db-supabase-seoul.md)(Vercel + Supabase 서울) · [ADR 0028](./0028-login-kakao-better-auth-session.md)(카카오 로그인) · [ADR 0029](./0029-image-storage-supabase-two-buckets.md)(이미지 Supabase Storage)
- **본 문서는 법률 자문이 아니다.** 공개 자료를 읽은 판단이며, 아래 "출시 전 확인"을 거쳐 최종 확정한다.

## Context

개인정보처리방침은 8단계에 본문을 확정하고, 처리위탁 수탁자·국외 이전·접속 로그 보관기간을 9단계 이후로 남겼다(`[ ]` 표시). 9단계 ①~⑧로 외부 업체가 모두 정해졌다.

- 저장 위치: DB·이미지 모두 Supabase 서울(`ap-northeast-2`), 서버 함수는 Vercel 서울(`icn1`). 두 회사 모두 **미국 회사**다.
- 개인정보 보호법 제28조의8은 국외로 **제공(조회되는 경우 포함)·처리위탁·보관**하는 것을 국외 이전으로 보고, 계약 이행에 필요한 처리위탁·보관은 처리방침 공개 등으로 동의 없이 할 수 있게 한다(제1항 제3호).
- 회사 DB에는 IP를 저장하지 않는다(ADR 0010). 접속 로그는 인프라가 자동으로 남기는 것뿐이며, 2026-11-17 확인 기준 보관기간은 Vercel 런타임 로그 Hobby 1시간·Pro 1일, Supabase API·DB 로그 무료 1일·Pro 7일이다(변경될 수 있어 출시 전 재확인).
- 카카오는 회원이 카카오 계정으로 본인 확인을 하면 회원번호를 알려 주는 쪽이며, 회사의 업무를 대신 처리하지 않는다.

## Decision

1. **처리위탁 수탁자는 Vercel Inc.(서비스 운영 서버·접속 로그 처리)와 Supabase Inc.(회원·시향기 데이터 저장, 향수 이미지 저장) 두 곳**으로 적는다. 보유 기간은 위탁 계약 종료 시.
2. **카카오는 수탁자로 적지 않는다.** 대신 제1조 수집 방법에 "카카오로부터 제공받음"을 적고, 제6조에 위탁이 아닌 이유를 한 문장으로 밝힌다.
3. **국외 이전은 보수적으로 공개한다.** 저장은 서울이지만, 미국 회사인 수탁자가 운영·장애 대응 중 국외에서 처리·조회할 수 있으므로 "해당 없음"으로 쓰지 않고 제28조의8 제1항 제3호에 따른 표(이전받는 자·국가·항목·시기·방법·목적·보유 기간·거부 방법)를 공개한다. 수탁자 연락처는 각 사 DPA(개인정보 처리 계약)를 확인해 출시 전에 기재한다.
4. **접속 로그 보관기간은 "서비스 제공 업체 설정에 따라 최대 7일 보관 후 자동 삭제"** 로 적는다. 무료·유료 플랜 어느 쪽이든 사실에 맞는 상한이다. 로그 보관을 늘리는 설정(로그 드레인 등)을 도입하면 이 문구를 함께 고친다.

## 출시 전 확인 (Launch Gate에 추가)

1. **통신비밀보호법의 접속 기록(로그기록자료) 3개월 보관 의무**가 이 서비스에 적용되는지. 적용되면 7일이 아니라 3개월 보관을 위한 설정(유료 플랜·로그 드레인 등)과 문구 변경이 필요하고 ⑩ 비용에 반영한다.
2. **카카오를 수탁자 표에서 빼는 해석**이 맞는지.
3. Vercel·Supabase의 DPA로 수탁자 연락처·처리 국가를 확인하고 `[출시 전 기재]`를 채운다. 로그 보관기간 수치도 재확인한다.

확인 창구: 개인정보 침해 신고센터(국번 없이 118, 무료 상담) 또는 전문가 검토(처리방침 머리말의 "서비스 개시 전 전문가 검토").

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 서울 저장이므로 국외 이전 "해당 없음" | 미국 회사의 국외 처리·조회 가능성을 숨기는 셈이 되고, 법은 조회도 이전으로 본다. 공개 비용은 문구뿐이다 |
| 카카오를 수탁자로 기재 | 실무에서 혼용되지만, 카카오는 회사 업무를 대신 처리하지 않는다. 사실과 다른 기재를 피한다(출시 전 확인 항목으로 남김) |
| 접속 로그 "3개월"로 기재 | 실제 보관 기간(최대 7일)과 달라 사실과 맞지 않는다. 3개월 의무 적용 여부는 확인 후 결정한다 |

## Consequences

- (+) 처리방침의 `[ ]` 중 9단계가 채울 수 있는 칸이 모두 채워졌다. 남은 `[ ]`는 운영자 명칭·문의 이메일·보호책임자·개시일·수탁자 연락처로, 모두 출시 전 항목이다.
- (+) 국외 이전을 미리 공개해 나중에 문구를 고치거나 재고지할 위험이 줄었다.
- (−) 통신비밀보호법 적용으로 결론 나면 로그 보관 설정과 비용이 늘어난다.
- (−) 수탁자 업체나 플랜이 바뀌면 제6조와 이 ADR을 함께 갱신해야 한다.
