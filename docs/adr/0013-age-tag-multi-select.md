# 0013. 나이대 태그를 단일 선택 → 1~3개 다중 선택으로 변경

- Status: **Accepted** (2026-09-13 확정)
- Supersedes: [0006](./0006-tag-vocabulary-and-answer-structure.md)의 나이 질문 응답 규칙("정확히 1개") — 그 외 내용(선택지 세트, 성격 규칙 등)은 그대로 유지
- 관련 문서: [0007-reduce-tag-questions-to-two.md](./0007-reduce-tag-questions-to-two.md), [05-data-model.md](../05-data-model.md) §1.1·§3.7 E10·§8, [04-wireframes.md](../04-wireframes.md) §1.3·§2.8·§4.1

## Context

ADR 0006이 나이 질문을 "정확히 1개(단일 선택)"로 확정한 이후, 나이대 하나만으로 향수가 사람이라면 몇 살일지 표현하기 어렵다는 문제가 드러났다("20대 초반과 30대 초반 사이 느낌" 같은 응답을 강제로 하나만 고르게 함). 성격 질문은 이미 이런 표현 폭 문제를 1~3개 다중 선택으로 해결해뒀다(ADR 0006).

## Decision

나이 질문의 응답 규칙을 성격과 동일하게 **1~3개 다중 선택**으로 바꾼다. 선택지 세트(10대/20대/30대/40대/50대+ 5구간)와 탭만으로 응답하는 방식은 변경하지 않는다.

- **대표 태그 규칙도 성격과 동일하게 적용**: 피드 카드에는 여전히 나이대 대표 태그 1개만 노출하고, **사용자가 먼저 고른 나이대 태그**를 대표로 쓴다. 시향기 상세의 "이 사람의 프로필" 표에는 선택한 나이대 전부를 노출한다(성격과 동일한 표시 방식).
- 데이터 구조 변경은 없다. E10(시향기 태그 답변)이 이미 질문 코드마다 여러 행(선택지 코드 + 선택 순서)을 허용하는 범용 구조이므로, 나이 질문에 적용되는 카디널리티 제약(정확히 1개 → 1~3개)만 바뀐다.

## 검토한 대안

- **대표 태그는 성격 1개만 노출, 나이대는 카드에서 생략**: 카드 한 줄 요약이 더 간결해지지만, 나이·성격 두 축을 보여주는 기존 카드 컨셉(§1.3 ⓒ)이 깨지고 "이 사람의 프로필" 인상이 약해져 기각.
- **최대 개수를 3개가 아닌 2개로 제한**: 인접한 두 구간(예: 20대·30대)만 허용하면 충분하다는 안. 성격과 규칙을 다르게 가져갈 근거가 약하고, 구현·검증 로직만 늘어나 기각. 성격과 동일하게 최대 3개로 통일.

## Consequences

- (+) 성격과 나이대의 응답 규칙·대표 태그 규칙이 완전히 동일해져 6단계 ERD의 태그 답변 테이블 제약을 질문별 분기 없이 하나로 통일할 수 있다.
- (+) E10 구조 변경이 필요 없다 — 선택 순서 필드가 이미 범용으로 설계되어 있었다(2026-09-11 확정 당시에는 성격만 염두에 뒀으나 결과적으로 재사용됨).
- (−) 7단계 API 검증 규칙에서 "나이 = 정확히 1개"로 하드코딩하면 안 되고, 성격과 같은 1~3개 검증 로직을 공유해야 한다.
- (−) 04-wireframes.md·05-data-model.md의 기존 "나이대는 단일 선택" 서술을 모두 정정해야 한다(본 ADR과 함께 반영).
