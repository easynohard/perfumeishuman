# 0014. 시향기 쓰기는 로그인 이후에만 — `/write` 진입 자체를 로그인 필수로 되돌림

- Status: **Accepted** (2026-09-13 확정)
- 관련 문서: [02-user-stories.md](../02-user-stories.md) C1·D1, [03-sitemap-ia.md](../03-sitemap-ia.md) §0·FL3, [04-wireframes.md](../04-wireframes.md) §1.4·§4.1, [05-data-model.md](../05-data-model.md) §3.1·§3.2
- 관련 ADR: [0002 열람은 비로그인 개방, 작성·추천은 소셜 로그인 필수](./0002-open-reading-login-for-actions.md) (대체하지 않음 — 작성 진입 시점 세부만 수정)

## Context

2026-08-19에 "게스트도 `/write`에 진입·입력할 수 있고, 로그인은 [등록] 버튼을 누르는 순간에만 요구하며 그때까지의 입력은 보존되어 로그인 후 자동 등록된다"로 정책을 바꿨다 (CLAUDE.md·02·03·04에 반영, 별도 ADR 없이 기록). 이번에 사용자가 이 결정을 다시 뒤집기로 했다 — "시향기 쓰기" 버튼을 누르는 순간 로그인 바텀시트를 먼저 거치고, 로그인을 마친 뒤에야 (선택했던 향수가 채워진) 빈 작성 화면에 진입하는 방식으로 되돌린다.

이는 사실 [ADR 0002](./0002-open-reading-login-for-actions.md)의 원래 문구("게스트가 추천/작성을 **시도하는 순간**에만 로그인을 유도")와 더 가깝다 — 08-19 변경이 "시도하는 순간"을 "등록 버튼을 누르는 순간"으로 좁게 해석해 벌어진 이탈이었고, 이번 결정으로 "작성을 시도하는 순간" = "시향기 쓰기 버튼을 누르는 순간"으로 되돌아간다.

## Decision

- `/write`는 **로그인해야 진입할 수 있는 화면**이다. 향수 상세의 "시향기 쓰기" 고정 바, 쓰기 탭, 빈 상태 버튼 등 어느 경로로 접근해도 게스트라면 로그인 바텀시트를 먼저 거친다.
- 로그인 완료 후에는 원래 하려던 행동(어떤 향수를 선택했는지)으로 그대로 이어져 **빈 작성 화면**이 열린다. "입력 내용을 보존했다가 로그인 후 자동 등록"하는 메커니즘은 더 이상 필요 없다 — 애초에 로그인 전에는 입력할 화면 자체가 없기 때문이다.
- **추천(C2·FL4)과 MY 탭 로그인 버튼은 이번 결정의 영향을 받지 않는다** — 계속 "시도하는 순간" 게이트가 뜨고 완료 후 그 자리로 복귀한다. 이번 변경은 오직 "쓰기" 트리거에만 적용된다.
- 로그인 완료 후 작성 중 자동 임시저장(브라우저 로컬)은 그대로 유지한다 — 이제는 로그인한 사용자만 쓰므로 "게스트라서 서버에 붙일 계정이 없다"는 기존 근거는 사라졌지만, 로컬 임시저장 자체를 바꿀 이유도 없어 메커니즘은 그대로 둔다.

## 검토한 대안

- **08-19 정책 유지 (등록 시점 게이트)**: 작성 화면까지는 로그인 벽 없이 열어 이탈을 줄이는 안. 이번에 사용자가 직접 기각 — 빈 화면에 공들여 쓴 뒤 등록 단계에서 로그인을 요구받는 경험이 오히려 더 이탈을 유발한다고 판단.

## Consequences

- (+) "입력 보존 → 로그인 후 자동 등록"이라는 별도 상태 전이가 사라져 `/write` 화면과 로그인 바텀시트의 상호작용이 단순해진다 (게스트용 임시 입력 보존 로직 불필요).
- (+) `/write`가 이제 멤버 전용 화면으로 일관되게 분류된다 — 04-wireframes.md가 `/write`를 "멤버 전용 화면" 절에 두면서도 게스트 진입을 허용하던 기존의 문서 내부 모순이 해소된다.
- (−) 로그인→작성 전환율(N3)에서 이탈이 더 일찍(쓰기 버튼을 누른 직후) 발생할 수 있다 — 8단계 UI에서 바텀시트 문구·속도로 이 지점의 이탈을 최소화해야 한다.
- (−) 이 결정으로 8단계 이전까지 CLAUDE.md·02·03·04에 남아 있던 "게스트 작성 가능" 관련 서술을 전부 이번 커밋에서 함께 고쳐야 한다 (반영 범위: CLAUDE.md, 02-user-stories.md, 03-sitemap-ia.md, 04-wireframes.md, 05-data-model.md).
