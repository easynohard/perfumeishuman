# 0027. 호스팅은 Vercel, DB는 Supabase(PostgreSQL)로 하고 둘 다 서울 리전에 둔다

- Status: **Accepted** (2026-11-16 — 9단계 기술 스택 2번 결정, 사용자 승인)
- 관련 문서: [ADR 0017](./0017-api-design-principles.md)(serverless 우선·개인정보 국내 리전·비용 최소화), [ADR 0026](./0026-nextjs-typescript-single-codebase.md)(Next.js), [ADR 0010](./0010-minimal-personal-data-collection.md), [06-erd.md](../06-erd.md), [legal/privacy-policy.md](../legal/privacy-policy.md) 제6조

## Context

ADR 0026으로 Next.js 한 코드베이스가 정해졌다. 이제 그 프로그램을 실행할 곳(호스팅)과 데이터를 저장할 곳(DB)을 정해야 한다. 7단계가 넘긴 제약은 **serverless 우선 검토, 개인정보는 국내 리전 필수, 비용 최소화**다(ADR 0017). 운영자는 1인이고 처음 개발한다(N8).

이 서비스가 저장하는 개인정보는 로그인 공급자 구분·공급자 회원번호·자동 생성 닉네임·동의 이력·최종 로그인 시각뿐이다(ADR 0010). 이것이 해외 리전에 저장되면 개인정보 보호법상 국외이전 고지(경우에 따라 별도 동의) 절차가 생기므로, 저장 위치를 서울로 고정해 그 절차를 피한다.

2026-11-16 기준으로 확인한 사실(가격은 결정 시점마다 공식 페이지로 재확인):

- Vercel은 함수 실행 리전으로 `icn1`(서울, AWS ap-northeast-2)을 지원한다. Hobby 플랜은 함수 리전 1개, **개인·비상업 용도로만** 쓸 수 있다. 상업적 이용은 Pro(사용자당 월 $20)가 필요하다. Hobby는 사용량 한도를 넘으면 해당 기능이 30일 동안 멈춘다.
- Supabase는 프로젝트 리전으로 서울(`ap-northeast-2`)을 고를 수 있다. 무료 플랜은 DB 500MB이고, 7일 동안 사용이 없으면 일시정지된다. Pro는 월 $25다.
- Neon은 공식 리전 목록에 서울이 없다.

## Decision

1. **호스팅: Vercel.** 함수 리전을 **`icn1`(서울)** 로 고정한다.
2. **DB: Supabase가 관리하는 PostgreSQL.** 프로젝트 리전을 **`ap-northeast-2`(서울)** 로 만든다. 리전은 생성 후 바꿀 수 없으므로 생성 시점에 확인한다.
3. 개발 기간에는 두 서비스 모두 **무료 플랜**을 쓴다. 유료 전환 시점(출시 시점 Vercel Pro 전환 등)은 9단계 ⑩ 비용 추정에서 정한다. **수익화(W1)를 도입하는 순간 Vercel Pro는 필수**다(Hobby 비상업 조건).
4. Supabase의 부가 기능(로그인 Auth, 파일 Storage)은 이 ADR에서 채택하지 않는다. 각각 9단계 ③ 로그인·④ 이미지 결정에서 따로 판단한다. 특히 Auth는 카카오 연동 시 이메일을 요구하는지 확인해야 한다(ADR 0010).
5. Vercel·Supabase는 개인정보처리방침의 **처리위탁 업체**로 기재한다. Vercel의 전 세계 네트워크·로그 처리 등으로 해외에서 처리되는 정보가 있으면 **국외이전 항목**도 기재한다(9단계 ⑨).

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| AWS 전부 (Amplify Hosting + RDS/Aurora, 서울) | 모든 것이 서울 리전이고 한 회사라는 장점이 있다. 하지만 권한·네트워크 설정이 복잡해 초보 1인에게 부담이 크고, 무료 혜택 이후 DB 비용이 꾸준히 나간다. Next.js 새 기능 반영이 늦을 수 있다. **2순위**로 남긴다 |
| Vercel + Neon | Neon에 서울 리전이 없어 "개인정보 국내 리전 필수" 조건을 충족하지 못한다 |
| 국내 클라우드 (네이버 클라우드 등) | 저장 위치 면에서는 가장 확실하지만, Next.js serverless 배포 자료가 적고 서버를 직접 관리해야 해 N8(1인 운영)과 어긋난다 |

## Consequences

- (+) 개인정보가 서울에 저장되어 국외이전 절차 부담이 크게 줄어든다.
- (+) Vercel은 Next.js 제작사라 배포가 가장 단순하다. 코드를 올리면 자동 배포된다.
- (+) PostgreSQL은 표준 관계형 DB라 06 ERD를 그대로 옮길 수 있다. ADR 0023의 "삭제분 제외 1인 1향수 1시향기"는 부분 유니크 인덱스로 구현할 수 있다(9단계 ⑤에서 확정).
- (+) 개발 기간 비용은 0원이다.
- (−) 두 회사 모두 해외 사업자라 처리위탁(경우에 따라 국외이전) 고지가 필요하다.
- (−) Vercel Hobby의 비상업 조건과 한도 초과 시 30일 정지가 운영 위험이다. 출시 전 Pro 전환 여부를 반드시 정한다.
- (−) Supabase 무료 플랜은 7일 미사용 시 일시정지된다. 개발 중에 오래 쉬면 다시 켜야 한다.
- (−) 서비스 두 곳을 연결해야 하므로 DB 연결 문자열 같은 비밀값 관리가 필요하다(10단계 `.env.example`·설치 가이드).
