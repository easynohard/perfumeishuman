# 0005. 콘텐츠 URL에 SEO 슬러그 사용

- Status: **Accepted** (2026-08-11 확정)
- 관련 문서: [03-sitemap-ia.md](../03-sitemap-ia.md) §5-5

## Context

3단계 사이트맵에서 URL 경로를 영문 복수형(`/perfumes/:id` 등)으로 정하면서, `:id`의 실제 형태를 숫자 ID로 할지 SEO 슬러그로 할지가 남아 있었다.

이 서비스의 핵심 유입 경로 중 하나가 **공유 URL로 로그인 없이 열리는 시향기 상세**(B3, SEO)다. 향수 이름을 검색해서 들어오는 입문자가 첫 타겟이므로, 검색 엔진에 읽히는 URL이 유입에 직접 기여한다. 숫자 ID(`/perfumes/1042`)는 구현이 단순하지만 URL에 정보가 없고, 슬러그(`/perfumes/chanel-no5-edp`)는 검색 결과·공유 미리보기에서 내용이 드러난다.

한편 공개된 URL은 한번 퍼지면 바꾸기 어렵다 — 이 결정은 데이터 모델(슬러그 컬럼·유니크 제약)과 공개 URL 체계에 영향을 주므로 되돌리기 어렵다.

## Decision

향수·브랜드·계열·시향기의 URL 식별자는 **SEO 슬러그**를 사용한다 (`/perfumes/:slug`, `/brands/:slug`, `/notes/:slug`, `/reviews/:slug`).

세부 규칙은 6단계 ERD에서 확정한다:

- 슬러그 생성 규칙 (영문 변환 vs 한글 허용, 정규화)
- 중복 처리 (유니크 제약 + 접미사 등)
- 제목이 없는 시향기의 슬러그 소스 (한 줄 요약이 없는 서비스이므로 향수 슬러그 + 식별자 조합 등 검토)
- 작성자 프로필(`/users/:id`)의 식별자 형식

## 검토한 대안

- **숫자/난수 ID**: 구현 단순, 슬러그 관리 불필요. 그러나 SEO·공유 미리보기에서 정보가 없어 유입 전략과 충돌하여 기각.
- **하이브리드(`/perfumes/1042-chanel-no5`)**: ID로 조회하고 슬러그는 장식으로 두는 방식. 리다이렉트·정규화(canonical) 처리가 필요하지만 슬러그 변경에 강함 — 6단계에서 시향기에 한해 재검토 여지를 남긴다.

## Consequences

- (+) 검색 유입·공유 미리보기에서 URL만으로 내용이 전달된다 — 입문자 유입 전략(1단계)과 정합.
- (+) 관리자 카탈로그 등록 시 슬러그가 함께 만들어져 URL 체계가 예측 가능해진다.
- (−) 향수·브랜드·계열·시향기 테이블에 슬러그 컬럼과 유니크 제약이 필요하다.
- (−) 이름 변경 시 슬러그 변경 여부·구 URL 리다이렉트 정책이 필요하다 (6단계에서 정의).
- 공개 후에는 URL 체계를 바꾸면 기존 공유 링크가 깨지므로, 변경하려면 새 ADR과 리다이렉트 계획이 필요하다.
