## 1. 디자인 원칙

1. **서비스의 주인공은 글이다.** 화면은 흰 종이, 색은 글을 가리키는 표지다. 사진·일러스트 없이도 완성돼야 한다(향수 이미지는 언제든 내려갈 수 있다 — ADR 0009).
2. **장난기는 카피에, 절제는 시각에.** 재미는 "이 향수가 사람이라면?"이라는 말에서 나온다. 색은 세 가지(흰색·코발트·검정)로 제한해 말이 도드라지게 한다.
3. **색은 역할로만 쓴다.** 코발트 = "누를 수 있다·선택됐다·반응했다", 검정 = "읽을 내용·무겁게 확정할 행동", 흰색 = 바탕. 장식으로 쓰지 않는다.
4. **모바일 360px 한 손 조작이 기준이다.** 데스크톱은 같은 UI를 가운데 정렬로 넓히고, 관리자 화면만 데스크톱 우선이다.
5. **별점의 시각 언어를 쓰지 않는다**(ADR 0001). 별·점수 막대·평점 숫자 모양 요소는 만들지 않는다. 반응은 "추천" 하나다.

## 2. 디자인 토큰

구현에서는 CSS 변수로 그대로 옮긴다(이름 고정). 값은 `style-guide.html`의 `:root`와 동일하다. 이 변수를 Tailwind 테마에 연결해 쓰고(`--cobalt` → `bg-cobalt`), 여기 없는 색은 테마에 등록하지 않는다([ADR 0032](./adr/0032-css-tailwind-with-token-only-theme.md)).

### 2.1 색상 — [ADR 0024](./adr/0024-color-system-white-cobalt-black.md)

| 토큰 | 값 | 용도 | 흰 바탕 대비 |
|---|---|---|---|
| `--white` | `#FFFFFF` | 페이지·카드·시트 바탕 | — |
| `--ink` | `#0A0A0A` | 본문·제목·검정 버튼·토스트·관리자 영역 | **19.8 : 1** |
| `--cobalt` | `#0047AB` | 주 행동 버튼·링크·선택 상태·추천 | **8.4 : 1** |
| `--cobalt-strong` | `#003580` | 눌림(hover/active)·링크 눌림 | 11.5 : 1 |
| `--cobalt-tint` | `#EEF3FC` | 선택된 칩 배경·행 hover·말풍선·안내 박스 | ink 17.8 : 1 / cobalt 7.6 : 1 |
| `--muted` | `#595959` | 보조 설명·메타·placeholder 외 보조 텍스트 | **7.0 : 1** |
| `--line` | `#E4E4E7` | 구분선·카드 테두리(장식) | 1.3 : 1 — **정보 전달에 쓰지 않는다** |
| `--line-strong` | `#767676` | 입력창·체크박스 테두리(조작 요소의 경계) | **4.5 : 1** (비텍스트 3 : 1 이상) |
| `--scrim` | `rgba(10,10,10,.5)` | 시트·모달 뒷배경 | — |

- 중립색은 순수 무채색 회색만 쓴다. 파란 기운이나 따뜻한 회색을 섞지 않는다(코발트가 유일한 유채색).
- 코발트 바탕 위 글자는 흰색만(8.4 : 1). 검정 바탕 위 코발트 글자는 쓰지 않는다(2.4 : 1, AA 미달). 검정 위에서 강조가 필요하면 흰색 굵게.
- **위험·오류·성공에 별도 색을 두지 않는다.** 색 대신 아이콘 + 문구 + 굵기로 구분한다(§2.6 상태 표현 규칙). 이는 팔레트 제약에서 오는 의도적 선택이며, 사용자 테스트에서 오류 인지가 약하다고 나오면 ADR 0024를 대체해 단일 경고색 도입을 검토한다.

### 2.2 서체 — [ADR 0025](./adr/0025-typeface-and-icon-set.md)

- **Pretendard Variable** (SIL OFL 1.1) 셀프 호스팅, `woff2` 동적 서브셋, `font-display: swap`. 구성: npm `pretendard` 패키지의 공식 동적 서브셋 CSS를 같은 출처에서 제공, 장기 캐시([ADR 0031](./adr/0031-font-icon-bundling-official-packages.md)).
- 폴백: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif`.
- 숫자(추천 수·글자 수)는 `font-variant-numeric: tabular-nums`. 별도 모노스페이스 서체는 쓰지 않는다.
- 한글 줄바꿈: `word-break: keep-all; overflow-wrap: anywhere`. 100자 서술이 어절 중간에서 끊기지 않게 한다.

| 스타일 | 크기 / 행간 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| Display | 24 / 1.35 | 800 | 향수 상세의 향수명 |
| Title | 18 / 1.4 | 800 | 화면 제목·시트 제목 |
| Body-L | 16 / 1.7 | 600 | **시향기 서술(주인공 글)** — 상세에서 |
| Body | 15 / 1.65 | 500 | 카드 서술·본문 |
| Label | 13 / 1.4 | 700 | 버튼·탭·칩 |
| Caption | 12 / 1.5 | 500 | 메타·고지·보조 (최소 크기 — 12px 미만 금지) |

시연 데모의 11px 텍스트는 12px로 올려 구현한다(N10 가독성).

### 2.3 간격·모서리·그림자

- 간격: 4px 배수 — `4 8 12 16 20 24 32 40`. 화면 좌우 여백 **16px**.
- 모서리: 칩·배지 `8`, 입력·버튼 `12`, 카드 `14`, 시트 상단 `20`, 아바타·알약 `999`.
- 테두리: 카드 `1px --line`. 선택·포커스 상태는 `1.5~2px --cobalt`.
- 그림자: **기본 없음**(평면). 바텀시트·모달·토스트에만 `0 8px 30px rgba(10,10,10,.12)`.

### 2.4 레이아웃·반응형

| 구간 | 폭 | 동작 |
|---|---|---|
| 모바일 (기준) | 360~599 | 1열, 하단 탭바, 하단 고정 바 |
| 태블릿 | 600~1023 | 콘텐츠 열 최대 **560px** 가운데 정렬, 양옆 흰 여백. 시트는 열 폭에 맞춤 |
| 데스크톱 | ≥1024 | 같은 560px 열 유지 + 상단 로고 바(탭바는 하단 유지). 시향기 피드를 2열로 늘리지 않는다 — 읽기 흐름이 깨진다 |
| 관리자 | ≥1024 우선 | 좌측 내비 160px + 본문 표. 모바일에선 내비를 상단 가로 탭으로 |

- 안전 영역(`env(safe-area-inset-bottom)`)을 하단 탭바·고정 바에 적용한다.
- 가로 스크롤은 만들지 않는다(표는 관리자 화면에서만 가로 스크롤 허용).

### 2.5 모션

- 200ms 이하의 짧은 전환만. 시트는 아래에서 올라오기(220ms), 모달은 살짝 커지며 등장(180ms), 추천 버튼 눌림은 채움 전환(120ms).
- `prefers-reduced-motion: reduce`에서는 위치 이동·확대를 끄고 불투명도 전환만 남긴다.
- 로딩은 스켈레톤(회색 블록) 우선, 스피너는 버튼 안 제출 중 표시에만.

### 2.6 상태 표현 규칙 (색 단독 금지)

| 상태 | 표현 |
|---|---|
| 선택됨 | 코발트 테두리 2px + `--cobalt-tint` 배경 + **체크 아이콘** + 굵게 |
| 비활성 | `--muted` 글자 + 점선 테두리 + `aria-disabled` (누르면 이유를 토스트로) |
| 오류 | 입력창 아래 `⚠`(Lucide `triangle-alert`) + 검정 굵은 문구 + 입력창 테두리 검정 2px |
| 성공 | 검정 토스트 + `✓` 아이콘 + 문구 |
| 위험한 확정(탈퇴·삭제) | **검정 채움 버튼**, 코발트 버튼과 나란히 두지 않는다. 확인 체크 전엔 비활성 |
| 포커스 | 모든 조작 요소 `outline: 2px solid --cobalt; outline-offset: 2px` (검정 바탕 위에서는 흰색) |

## 3. 아이콘·이미지

- 아이콘: **Lucide** (ISC), 24px 격자, 선 두께 1.75, `currentColor`. npm `lucide-react`에서 쓰는 아이콘만 불러와 인라인 SVG로 포함 — 외부 CDN 호출 없음([ADR 0031](./adr/0031-font-icon-bundling-official-packages.md), 0025의 "스프라이트"를 대체).
- 사용 아이콘(초기 세트): `search` `pen-line` `user-round` `heart`(추천) `share` `ellipsis` `chevron-left` `chevron-right` `x` `check` `triangle-alert` `info` `shuffle`(질문 카드) `log-out` `trash-2` `eye-off`(관리자 비공개) `shield`(관리자).
- **추천 아이콘은 하트가 아니라 손뼉·엄지 같은 평가 암시를 피한다** — 하트는 "좋아요"로 읽혀 별점 계열과 거리가 멀고 친근하다. 채움(추천함)/윤곽(안 함)으로만 구분한다.
- 향수 이미지는 **정사각 투명 누끼**, 흰 바탕 위에 그대로 둔다(그림자·배경 박스 없음). 로고·일러스트·일반 사진은 MVP에 없다.
- **텍스트 카드 폴백**(필수, ADR 0009): 이미지가 없으면 같은 자리에 정사각 박스(`--cobalt-tint` 바탕, 테두리 없음) 안에 브랜드명(Caption, 코발트) + 향수명(Title, 검정)을 중앙 정렬. 박스 크기는 이미지와 같아 레이아웃이 변하지 않는다.
- 로고: 워드마크(글자만) "향수가 사람이라면?" — Pretendard 800, `?`만 코발트. 별도 이미지 에셋 없음.

## 4. 컴포넌트

(실물은 스타일 가이드 참조. 크기는 터치 타겟 **최소 44×44px**.)

### 4.1 버튼

| 종류 | 모양 | 용도 |
|---|---|---|
| Primary | 코발트 채움 + 흰 글자, 높이 48, 모서리 12 | 화면당 1개. 로그인·"내가 아는 {향수}은/는 이래요"·고정 바 "시향기 쓰기" |
| Secondary | 흰 바탕 + 코발트 1.5px 테두리 + 코발트 글자 | 보조 행동 (더보기, 취소) |
| Ink | 검정 채움 + 흰 글자 | 탈퇴 확정·삭제 확정·관리자 주 행동 |
| Ghost | 배경 없음 + 코발트 글자 | 인라인 링크 행동 (수정, 신고) |
| Disabled | `--line` 배경 + `--muted` 글자 | 필수 미충족 — 누르면 미충족 위치로 스크롤 + 흔들림(100ms) |

### 4.2 추천 버튼 (서비스의 단일 반응 장치)

- 대기: 흰 바탕 + 코발트 1.5px 테두리 + 윤곽 하트 + "추천 128".
- 추천함: 코발트 채움 + 흰 글자 + 채운 하트 (`aria-pressed="true"`). 재탭하면 취소.
- 본인 글: 비활성(점선) + "내가 소개한 사람이에요".
- 게스트가 누르면 로그인 바텀시트(trigger=recommend). 숫자는 게스트에게도 항상 보인다.
- 추천 수는 탭 즉시 낙관적 갱신, 실패 시 되돌리고 토스트.

### 4.3 칩·태그

- 읽기 칩(대표 태그·계열): 흰 바탕 + `--line` 테두리 + 검정 글자, 높이 28, 모서리 8.
- 선택 칩(작성 폼): 높이 40. 선택 시 §2.6 선택됨 규칙. 상한 3개 도달 시 나머지는 비활성 + "최대 3개까지 고를 수 있어요".
- 대표 태그(피드 카드): 코발트 글자 + `--cobalt-tint` 배경 1~2개만.

### 4.4 시향기 카드 (변형 A·B — 04 확정 3)

```
┌──────────────────────────────┐   변형 A (피드·프로필·MY)
│ 딥티크 · 오 로즈     (Caption)│   브랜드 · 향수명: Label, 검정 / 브랜드는 muted
│ "첫 출근날 긴장한 신입사원 같은│   서술 전문 Body 15/600 — 100자 전부 노출, 말줄임 없음
│  사람. 말은 없는데 향이 먼저…"│
│ [20대] [다정한]    ♡ 128  닉네임│   칩 · 추천 수 · 작성자(탈퇴자는 링크 없는 텍스트)
└──────────────────────────────┘   변형 B는 첫 줄(브랜드·향수명)만 생략
```

- 카드 전체가 하나의 링크(시향기 상세). 내부 닉네임 링크는 별도 탭 영역으로 분리(중첩 링크 금지 → 카드 링크는 서술 영역에 걸고 닉네임은 형제 요소).
- 카드 간격 12, 테두리 `--line`, hover/focus 시 테두리 코발트.
- 삭제·이의 접수된 글은 카드가 존재하지 않는다(관리자 화면 제외).

### 4.5 입력

- 텍스트 입력 높이 48, 테두리 `--line-strong` 1.5px, 포커스 시 코발트 2px.
- 자유 서술(textarea): 최소 높이 112, 우하단 `23/100` (tabular-nums). 90자부터 글자 수가 검정 굵게, 100자에서 입력 제한 + 문구 "100자까지 쓸 수 있어요".
- placeholder는 `--muted`(7.0 : 1)이며 라벨을 대체하지 않는다. 입력창마다 보이는 라벨 또는 `aria-label`.

### 4.6 내비게이션

- 상단 탭(피드 / 브랜드로 찾기 / 계열로 찾기): 활성 탭은 검정 굵게 + 하단 코발트 2px. 가로 3등분.
- 하단 탭바(홈 / ✍ 쓰기 / MY, 높이 56 + 안전 영역): 활성은 검정 굵게+아이콘 채움, **쓰기만 코발트**(전환 행동 강조). 정책 3종 화면에는 탭바가 없다(04 확정 17).
- 향수 상세 하단 고정 바: 탭바 위에 Primary 버튼 한 줄 "✍ 이 향수의 시향기 쓰기". 이미 쓴 향수는 버튼 문구가 "이미 소개했어요"(Secondary)로 바뀌고 누르면 안내 토스트(ADR 0023).

### 4.7 바텀시트·모달·토스트

- 바텀시트: 상단 모서리 20, 그랩바 36×4, 뒷배경 `--scrim`, 아래로 스와이프·바깥 탭·X로 닫기. 포커스 트랩, 열릴 때 제목에 포커스, 닫히면 호출 요소로 복귀.
- 로그인 시트 구성: 트리거별 헤드라인 → 소셜 버튼(카카오 1개 — ADR 0028) → 동의 고지 텍스트(약관·처리방침 링크) → **"탈퇴 후에도 시향기는 익명으로 남는다"**(삭제 불가 문구, ADR 0008) → 복귀 안내. 동의 고지는 Caption 12px 이상, `--muted`.
- 모달(탈퇴 확인): 중앙 카드. 세 항목 순서 고정 — 삭제됩니다 → 남아요 → 되돌릴 수 없어요(04 §4.2). 체크박스 확인 전 Ink 버튼 비활성.
- 토스트: 검정 바탕 흰 글자, 하단 탭바 위 8px, 3초 후 소멸, `role="status"`. 중요한 안내는 토스트가 아니라 시트·인라인으로.

### 4.8 목록 행·빈 상태·배지·말풍선

- 목록 행: 높이 ≥56, 좌 텍스트·우 보조(시향기 수·추천 수), 하단 구분선, hover `--cobalt-tint`.
- 빈 상태: 중앙 정렬 문구(04 확정 9 "이 향수에 영혼을 불어넣어 사람으로 만들어주세요") + Primary 버튼. 일러스트 없음.
- 배지: "내 글"(코발트 채움·흰 글자), 관리자(검정 채움·흰 글자). 8 모서리, Caption.
- 말풍선(질문 카드 결과): `--cobalt-tint` 바탕, 모서리 `12 12 12 2`, 검정 글자. "다른 질문" 아이콘 버튼(`shuffle`).
- 프로필 표("이 사람의 프로필"): 2열 — 항목명(`--muted`, 56px 고정) / 답변 칩들. 행 사이 점선 `--line`.

### 4.9 관리자 컴포넌트

- 영역 구분: **검정 상단 바**(흰 글자 "관리자") — 일반 화면과 한눈에 구분. 본문은 흰 바탕.
- 표: 헤더 `--muted` 12px, 행 구분선, 삭제 행은 취소선 + `--muted` + "삭제됨 · 본인/관리자" 배지.
- 위험 행동(삭제·이미지 일괄 비공개)은 Ink 버튼 + 확인 모달(대상·수·되돌릴 수 없음 명시). 시향기가 달린 향수의 삭제 버튼은 비활성이며 옆에 시향기 수 안내(차단 — 07 `PERFUME_HAS_REVIEWS`).
- 이미지 등록 폼: 출처 URL 필수 + 수집 기준(팩샷만) 안내 박스(`--cobalt-tint`)를 입력칸 위에 상시 노출.

## 5. 카피 톤 (마이크로카피)

- 말투: **해요체**. 장난은 "사람 소개" 틀 안에서만 — 에러 메시지에 농담을 넣지 않는다.
- 고정 문구(04 확정 9): "{향수명}(이)가 사람이라면 (N)", "이 향수의 다른 페르소나", "내가 아는 {향수명}은/는 이래요", "이 향수에 영혼을 불어넣어 사람으로 만들어주세요".
- 조사 자동 처리(받침 유무)는 05 §2.7의 규칙을 따른다.
- 추가 문구(초안):

| 상황 | 문구 |
|---|---|
| 이미 쓴 향수 | "이미 소개했어요. 한 향수당 한 사람만 소개할 수 있어요" |
| 100자 도달 | "100자까지 쓸 수 있어요" |
| 태그 3개 도달 | "최대 3개까지 고를 수 있어요" |
| 필수 미충족 | "서술과 태그를 하나씩만 골라 주세요" |
| 본인 글 추천 시도 | "내가 소개한 사람이에요" |
| 네트워크 오류 | "연결이 잠깐 끊겼어요. 다시 시도해 주세요" |
| 삭제된 글(404) | "사라진 페르소나예요" + 홈 버튼 |
| 로그인 필요(쓰기) | "로그인하면 바로 소개할 수 있어요" |
| 로그인 필요(추천) | "마음에 들었다면 로그인하고 추천해 주세요" |

별점·평가 연상 표현("평점", "별로예요", "최고예요")은 쓰지 않는다.

### 6.12 정책·도움말 문서 템플릿 (공유)

- 상단 바: ← 뒤로 + 제목. **탭바 없음.** 뒤로 가면 직전 상태(작성 중 내용·열린 시트)가 복원돼야 한다 — 시트는 브라우저 히스토리 항목으로 취급한다.
- 본문 폭 최대 560, Body 15/1.8, 조 제목은 Title 18, 항 번호(①②)는 들여쓰기.
- 상단 요약 박스(`--cobalt-tint`): 시행일·버전 + 핵심 3줄("탈퇴해도 글은 익명으로 남아요" 등). 요약은 법적 효력이 없고 본문이 우선한다는 문구를 함께 둔다.
- 목차는 상단 고정 접힘 목록(조 단위 앵커). 이전 버전 목록은 맨 아래(`/terms`·`/privacy`만).
- 맨 아래 공통 푸터: "권리 침해 신고" 링크 → `/help#report`.
- `/help`는 사용법(쓰기·추천·탈퇴) → 커뮤니티 가이드 → 권리 침해 신고 창구 순서의 아코디언. 작성 화면 1줄 요약이 `/help#guide`로 연결된다.

## 7. 접근성 (N10 WCAG AA)

- 모든 텍스트 대비 AA 이상: 가장 약한 조합이 `--muted` on `--cobalt-tint` = 6.3 : 1, 흰 바탕 12px 보조 텍스트 7.0 : 1.
- 조작 요소 경계(입력·체크) 3 : 1 이상 → `--line-strong` 사용. 카드 테두리(`--line`)는 장식이며 의미를 전달하지 않는다.
- 키보드: 모든 조작 가능, 포커스 순서 = 시각 순서, 시트·모달은 포커스 트랩 + ESC 닫기.
- 의미 구조: 화면당 `h1` 하나, 카드 목록은 `<ul>`, 탭은 `role="tablist"`, 추천은 `aria-pressed`, 토스트는 `role="status"`, 입력 오류는 `aria-describedby`.
- 이미지: 대체 텍스트 "{브랜드} {향수} 제품 이미지"(05 §6). 폴백 카드는 텍스트 자체가 내용이므로 대체 텍스트 불필요.
- 확대: 200% 확대·텍스트 크기 변경에서도 가로 스크롤 없음. 고정 바가 본문을 가리지 않도록 본문 하단 패딩을 확보.
- 다크 모드: **MVP에서 제공하지 않는다**(흰 배경이 정체성). `color-scheme: light`를 명시해 브라우저 자동 반전을 막는다. 도입 시 별도 ADR.

## 8. 성능 (N5 FCP 2.5초)

- 서체: 첫 화면에 필요한 서브셋만 로드(동적 서브셋), `preload` 1개, 폴백 서체로 즉시 렌더 후 교체. 서체 파일은 같은 출처에서 제공.
- 아이콘: 인라인 SVG 스프라이트 — 요청 0건 추가.
- 이미지: 향수 이미지 `loading="lazy"`(첫 화면 상단 제외), 고정 가로세로 비율(CLS 방지), WebP.
- 첫 화면 CSS는 인라인 크리티컬 + 나머지 비동기. 토큰 수가 적어(색 8개) 번들이 작다.
