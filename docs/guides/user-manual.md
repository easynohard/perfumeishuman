# 사용자 매뉴얼 (도움말 · 커뮤니티 가이드) — 원문 초안

> 프로젝트: **perfumeishuman — "향수가 사람이라면?"**
> 작성일: 2026-11-12 · 상태: **🔶 초안 — 사용자 승인 대기**
> 이 문서는 `/help` 화면과 온보딩 문구의 원문이다. 말투는 해요체, 화면 문구는 [08-ui-design.md](../08-ui-design.md) §5를 따른다. `[ ]`는 운영 시작 전 확정할 값.
> 관리자 운영 매뉴얼(`admin-manual.md`)은 관리자 화면이 구현되는 10단계 이후에 작성한다.

---

## 1. 이 서비스는 뭐예요?

향수를 **사람으로 소개**하는 서비스예요. "이 향수가 사람이라면 어떤 사람일까?"를 100자 안에서 재미있게 써 보세요. 향을 잘 몰라도 괜찮아요. 별점도, 어려운 용어도 없어요. 마음에 들면 **추천**만 누르면 돼요.

## 2. 읽기 — 로그인 없이 구경해요

- **피드**: 추천을 많이 받은 시향기가 먼저 나와요. 10개씩 보고 [더보기]로 이어서 읽어요.
- **브랜드로 찾기 / 계열로 찾기**: 좋아하는 브랜드나 향 계열(플로럴, 우디 …)에서 향수를 찾아요.
- **검색**: 향수나 브랜드 이름으로 찾아요. 결과가 없어도 인기 향수를 보여 드려요.
- **향수 페이지**: 그 향수를 사람으로 소개한 글이 모여 있어요. 추천순/최신순으로 바꿔 볼 수 있어요. "필요없는 정보들"을 펼치면 계열과 노트가 나와요.
- 글 링크를 공유하면 로그인하지 않은 친구도 같은 글을 읽을 수 있어요.

## 3. 쓰기 — 로그인하고 소개해요

1. 향수 페이지에서 **✍ 이 향수의 시향기 쓰기**를 눌러요. 로그인하지 않았다면 먼저 로그인 창이 열려요. 로그인하면 고른 향수가 채워진 빈 화면으로 돌아와요.
2. **이 향수가 사람이라면, 어떤 사람인가요?** 100자 안에서 자유롭게 써요.
   - 막막하면 **질문 카드**를 눌러 보세요. "이 사람의 MBTI는?", "이 사람이 카페에서 시키는 메뉴는?" 같은 질문이 나와요. 질문은 사람이 직접 쓴 문구예요.
3. **나이대**와 **분위기**를 각각 1~3개씩 골라요. 탭만 하면 돼요.
4. **내가 아는 ○○은/는 이래요**를 눌러 등록해요.

알아두세요
- 한 향수에는 **시향기를 하나만** 쓸 수 있어요. 이미 쓴 향수는 "이미 소개했어요"라고 알려 드려요. 내 글을 지우면 같은 향수에 다시 쓸 수 있어요.
- 쓰는 도중 나가도 내용이 이 기기에 임시로 저장돼요(서버로 보내지 않아요).
- 등록한 뒤에도 서술과 태그를 고칠 수 있어요. 향수는 바꿀 수 없어요.

## 4. 추천

- 마음에 든 시향기를 한 번 눌러 추천해요. 다시 누르면 취소돼요.
- 시향기 하나에 한 번만 추천할 수 있고, **내 글에는 추천할 수 없어요.**
- 로그인 전에 추천을 누르면 로그인 후 바로 반영돼요.

## 5. 내 시향기 (MY)

- 내가 쓴 시향기와 **받은 추천 수**를 한눈에 봐요.
- 글마다 수정·삭제할 수 있어요. 삭제한 글은 목록과 피드에서 사라져요.
- 닉네임은 2~12자(한글·영문·숫자·공백)로 바꿀 수 있어요. `user_`로 시작하는 이름은 쓸 수 없어요.
- 로그아웃도 여기서 해요.

## 6. 회원 탈퇴

MY 맨 아래에서 탈퇴할 수 있어요. 탈퇴 전에 꼭 알아두세요.

1. **내 정보는 바로 지워져요** — 로그인 정보와 닉네임이 삭제돼요.
2. **내가 쓴 글과 추천은 남아요** — 작성자 이름만 `user_숫자`로 바뀌어요. 이름을 다시 알아낼 수 없어요.
3. **되돌릴 수 없어요** — 다시 가입해도 이전 글을 되찾거나 고칠 수 없어요.

남기고 싶지 않은 글은 탈퇴 전에 직접 삭제해 주세요.

## 7. 커뮤니티 가이드

모두가 편하게 웃을 수 있도록 부탁드려요.

- 실제 인물이나 단체를 비방하거나 **허위 정보**를 쓰지 않아요.
- 혐오·차별·불쾌한 표현은 안 돼요.
- 광고, 구매·가입 유도 링크, 반복 도배는 안 돼요.
- 연락처 등 **개인정보**를 쓰지 않아요.
- 다른 사람의 글을 베끼거나 권리를 침해하지 않아요.
- 시향기는 **재미있는 개인 감상**이에요. 향수의 객관적인 평가가 아니에요.

**신고하기**: 글 상세의 ⋯ 메뉴에서 신고할 수 있어요(로그인하지 않아도 돼요). 사유는 허위 정보 / 비방·혐오 / 스팸·광고 / 기타 중에 골라요. 내 글은 신고할 수 없어요. 운영자가 확인해서 삭제하거나 유지해요.

## 8. 권리 침해 신고 (브랜드·이미지·저작권)

서비스의 향수 이미지나 글이 내 권리를 침해한다고 생각하면 알려 주세요.

- 접수: [권리 침해 신고 이메일 — 운영 시작 전 확정]
- 적어 주실 내용: 성함·연락처(권리자 본인/대리인 여부), 권리를 주장하는 근거, 해당 페이지 주소(URL) 또는 브랜드, 요청하는 조치
- 처리: 먼저 **비공개 처리**하고, 접수 후 24시간 안에 회신, 72시간 안에 조치하도록 노력해요. 결과는 신고하신 분(그리고 글 작성자)에게 알려요.
- 조치에 이의가 있으면 재게시를 요청할 수 있어요.

향수 이름·브랜드·상표와 제품 이미지의 권리는 각 권리자에게 있고, 서비스는 어떤 브랜드와도 제휴·후원 관계가 아니에요.

## 9. 자주 묻는 질문

**별점은 없나요?** 없어요. 추천만 있어요.
**닉네임이 마음에 안 들어요.** MY에서 바꿀 수 있어요.
**이메일을 안 받는데 약관이 바뀌면 어떻게 알아요?** 서비스 안에 공지로 게시해요.
**내 정보는 뭐가 저장돼요?** 로그인 공급자 구분·회원번호, 닉네임, 동의 기록, 최종 로그인 시각이에요. 자세한 내용은 개인정보처리방침을 보세요.
**AI가 글을 만들거나 검열하나요?** 아니요. 질문 카드도 사람이 쓴 문구이고, 글 심사는 사람이 해요.
**글이 사라졌어요.** 본인이 삭제했거나 운영자가 가이드에 따라 삭제했을 수 있어요. 궁금하면 [문의 이메일]로 알려 주세요.
