## 2. 항목별 상세

### 2.1 Pretendard (폰트)

- 라이선스: SIL OFL 1.1. 상업적 이용·웹 임베딩·수정·재배포 허용. 금지: 폰트 소프트웨어 **단독 판매**, 수정본에 원본 예약 글꼴명(Reserved Font Name) 사용.
- 우리 사용 방식: 서브셋(woff2) 생성 후 셀프 호스팅. **서브셋 생성은 OFL상 수정에 해당할 수 있으므로** 예약 글꼴명이 있는 경우 서브셋 파일의 글꼴 이름을 확인한다(Pretendard 배포본은 이미 서브셋 배포를 허용). 9단계 번들 구성 때 재확인.
- 의무: 저작권 고지와 OFL 전문을 포함한다 → 서비스 안 "오픈소스 고지"와 리포 `THIRD_PARTY_NOTICES`.
- 출처 확인 URL(구현 시 기록): Pretendard 공식 저장소 LICENSE — [확인일·버전 기록란]

### 2.2 Lucide (아이콘)

- 라이선스: ISC. 상업 이용·수정·재배포 허용, 저작권·라이선스 고지 유지 조건. 일부 아이콘은 Feather(MIT) 유래라 MIT 고지도 함께 포함한다.
- 우리 사용 방식: 필요한 17개 안팎만 SVG 스프라이트에 인라인(스타일 가이드의 `heart`, `check`, `triangle-alert`, `pen-line`, `house`, `user-round`, `shuffle` 등 표본 포함).
- 의무: ISC·MIT 고지문을 `THIRD_PARTY_NOTICES`에 포함.
- 주의: **스타일 가이드의 SVG 경로는 Lucide 원본을 참고해 옮긴 것이므로** 구현 시 패키지에서 직접 가져오는 방식으로 교체해 출처를 추적 가능하게 한다.

### 2.3 색상

- 색상 값에는 저작권이 없다. 코발트 블루는 일반 색 이름이며, 특정 브랜드의 전용 색 사용 허락 문제는 없다. 단, 다른 향수 브랜드의 대표 색·로고 모양과 혼동되는 디자인은 피한다.

### 2.4 향수 이미지

- 이미지 권리는 각 브랜드에 있다. 사용 정당성은 이용 허락이 아니라 **ADR 0009의 정책**(단순 팩샷만, 연출컷·모델컷·워터마크 배제, 출처 URL·수집일 기록, 이의 시 즉시 비공개, 텍스트 폴백)에 의존한다.
- 감사 방법: 출시 전 관문에서 **이미지 전수에 대해 출처 URL·수집일·권리 상태가 기록돼 있는지** 쿼리로 확인(05 §6.1의 필수 필드 누락 0건). 수익화(W1) 도입 시 정책 재검토(ADR 0009).
- 8단계 디자인은 이미지 없이 완성되도록(텍스트 카드 폴백) 설계했다 → 이미지 전부 비공개되어도 UI가 깨지지 않는다.

### 2.5 제3자 서비스 호출 점검

- 디자인 단계에서 외부 서비스(Google Fonts, 아이콘 CDN, 분석 도구) 호출을 **도입하지 않았다.** 폰트·아이콘은 셀프 호스팅 전제(ADR 0025) → 방문자 IP가 제3자에게 전달되지 않는다.
